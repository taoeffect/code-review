# Code Review

An agent skill to perform a sophisticated and comprehensive code review, outputting it to a `REVIEW.md` file by default.

## Installation

```
$ npx skills add taoeffect/code-review
```

## Usage

1. Work in a branch that is *not* `master` or `main`
2. Commit your changes so that your working directory is clean
3. Run this skill (tell the LLM: `run the code-review skill`)
